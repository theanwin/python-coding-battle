CHALLENGE BREAKDOWN

Four Progressive Competition Rounds

Each round tests distinct competencies ranging from pure algorithmic reasoning to rapid hands-on Python execution.

ROUND 1 10 Mins • 20 Pts

Predict the Output

Analyze Python programs containing arithmetic precedence, floor division, string multiplication, boolean logic, and nested conditional structures. Solve mentally without using an online compiler.

Multiple-Choice Questions No Compiler Allowed
ROUND 2 10 Mins • 20 Pts

Find the Bug 🐛

Identify and fix intentional bugs including missing colons, invalid indentation, incorrect variable names, and bad comparison operators inside the embedded Python code editor.

Syntax & Logic Debugging Embedded Editor
ROUND 3 20 Mins • 30 Pts

Speed Coding ⚡

Rapid-fire algorithmic challenges: name printer, even/odd checker, basic calculator with division error handling, multiplication tables, and number-guessing simulation evaluated against automated test cases.

5 Core Challenges Auto Test-Case Scoring
ROUND 4 10 Mins • 20 Pts + Bonus

Final Boss 👑

Build a production-grade Student Grade Calculator. Must enforce nested if statements to verify both overall average and individual subject passing thresholds. First correct submission receives bonus points!

Nested If Requirement Speed Bonus Award
